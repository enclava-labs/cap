# Verification reason codes v1

Reason codes are the stable machine interface. `OK` means a check passed.

| Area | Codes |
|---|---|
| Input and policy | `MALFORMED_BUNDLE`, `MALFORMED_POLICY`, `NO_POLICY_SUPPLIED`, `UNSUPPORTED_REQUIRED_CHECK` |
| Request binding | `NONCE_MISMATCH`, `TARGET_ORIGIN_MISMATCH`, `TARGET_ORIGIN_REJECTED`, `CHANNEL_SPKI_MISMATCH`, `CHANNEL_SPKI_UNAVAILABLE` |
| AMD SNP | `INVALID_SNP_REPORT`, `INVALID_AMD_ENDORSEMENTS`, `AMD_CHAIN_INVALID_OR_UNTRUSTED`, `SNP_REPORT_SIGNATURE_INVALID`, `VCEK_REPORT_BINDING_INVALID`, `SNP_MEASUREMENT_REJECTED`, `SNP_POLICY_REJECTED`, `SNP_TCB_BELOW_MINIMUM`, `REPORT_DATA_MISMATCH` |
| AMD revocation | `AMD_REVOCATION_INVALID`, `VCEK_REVOKED`, `REVOCATION_DATA_EXPIRED`, `REVOCATION_DATA_STALE`, `REVOCATION_TIME_MISSING` |
| Runtime and supply chain | `INVALID_TLS_LEAF_CERTIFICATE`, `ARTIFACT_SIGNATURE_INVALID`, `ARTIFACT_RELATIONSHIP_INVALID`, `DESCRIPTOR_MEASUREMENT_MISMATCH`, `DEPLOYMENT_IDENTITY_REJECTED`, `IMAGE_DIGEST_REJECTED`, `RUNTIME_CLASS_REJECTED`, `SIDECAR_DIGEST_REJECTED`, `PLATFORM_RELEASE_REJECTED`, `PORTABLE_SUPPLY_CHAIN_MATERIAL_INVALID`, `SUPPLY_CHAIN_SIGNATURE_INVALID` |
| Appraiser receipt | `APPRAISER_RESPONSE_MALFORMED`, `APPRAISER_RESULT_HASH_MISMATCH`, `APPRAISER_RECEIPT_MISSING`, `APPRAISER_KEY_UNTRUSTED`, `APPRAISER_KEY_REVOKED`, `APPRAISER_KEY_NOT_YET_VALID`, `APPRAISER_KEY_EXPIRED`, `APPRAISER_RECEIPT_TIME_INVALID`, `APPRAISER_RECEIPT_EXPIRED`, `APPRAISER_RECEIPT_SIGNATURE_INVALID` |

Warnings are human-facing and non-authoritative. `LIVE_TLS_CHANNEL_BINDING_NOT_CHECKED`
accompanies `CHANNEL_SPKI_UNAVAILABLE`; it is not a substitute for the check outcome.
